# Roadmap

## 0.1 — Explainable baseline

- Deterministic checks for agent instruction and CI trust boundaries.
- Text, JSON, and SARIF reporting.
- Public threat model and contribution process.

## 0.2 — Parser hardening

- Structured GitHub Actions analysis with preserved source locations.
- Fuzz tests for malformed UTF-8, large lines, and adversarial YAML.
- Baseline files for reviewing only newly introduced findings.

## 0.3 — Ecosystem validation

- Publish an installable package and signed release artifacts.
- Test against opt-in public repositories and document false-positive rates.
- Add a reusable GitHub Action with minimal permissions.
- Stabilize the rule schema based on maintainer feedback.

Roadmap items are plans, not completed features.
